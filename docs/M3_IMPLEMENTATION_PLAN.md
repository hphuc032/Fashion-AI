## Providers, voice and privacy

FunASR primary adapter uses explicitly installed local timestamp-capable model (Paraformer), no implicit hub alias/download or remote code; optional local VAD/punctuation/diarization models only when configured. Faster-whisper alternative uses local tiny/base CT2 model, int8 CPU2threads, forced zh; no fabricated confidence. Bound phrases/timestamps to actual chunk duration. Process chunks sequentially with overlap ownership and duplicate/partial-boundary reconciliation, default speaker when no local diarization; allow manual speaker assignment. Preserve raw text/punctuation and record available confidence/speaker only. ASR inference/model reuse within one disposable worker; separate ASR/translation/TTS jobs avoid observed native DLL conflicts and release memory.

Local TTS: sherpa-onnx VITS/Piper vi_VN vais1000 medium, one speaker22,050Hz; confirm voice/model metadata and license before synthesis. System TTS may be optional explicit fallback; never fabricate an available voice. Optional Azure: credentials environment-only, live voice-list validation, explicit cloud selection/consent before text transmission, no source audio upload. Provider advertises unsupported pitch/gender controls truthfully. Voice preview is a short queued job before full dub; global default plus per-speaker explicit overrides, no cloning or imitation. Cache key covers text, model manifest/provider identity and all voice settings. Retry transient errors, never invent audio/translation on failure. Application startup never downloads models or makes cloud calls.
