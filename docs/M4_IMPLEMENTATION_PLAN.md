## ASS and compatibility

Generate UTF-8 ASS v4+, original M3 start/end (centisecond quantization ≤10ms); never use OCR captions as spoken subtitles or independently retime phrases. Clip/shift only explicit preview interval; record original and output event times. Validate finite/nonnegative bounds, approval/text, cap events, glyphs. Conservative wrapping/shrink within two lines; do not truncate. Short/high-reading-rate events warn/require explicit acknowledgement, no invented word alignment. Speaker-specific styles and automatic vertical stacking for overlapping speakers; block insufficient safe space.

Reuse system Arial/Segoe UI/DejaVu discovery and FontTools glyph checking. White/black-outline/subtle shadow/bottom-center/mobile margins, responsive sizing, color/outline/font/position/line-spacing/background/margins configurable. Safely escape text braces/backslashes/newlines; no arbitrary override tags from user text. Known relative subtitle/fonts paths under job cwd avoid Windows filter colon/quote injection; local font copies only in ignored staging, no font redistribution.

Burn-in default with verified libass. FFmpeg MP4 codec table supports mov_text, not native ASS. Soft MP4 therefore requires explicit compatibility confirmation to convert generated ASS→mov_text; original ASS sidecar retained, advanced style/placement not promised in all players. Never call embedded mov_text an ASS track. Unsupported capability errors are actionable.
