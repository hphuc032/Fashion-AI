# Windows troubleshooting

- **Distribution incomplete:** extract the whole ZIP. FashionAILocalizer.exe, _internal, _runtime, _code and tools must stay together; moving only.exe will fail.
- **Runtime check fails:** read data/logs/runtime-check.log (curated exception type), runtime-check.json when available and streamlit.log. Do not post config.env or logs publicly without reviewing them for source text/private paths. --check reports versions, fonts, FFmpeg features and model presence, not secret values.
- **DLL or import errors:** use the matchingx64CPython3.11/pinned build. Never copy random DLLs or disable antivirus. Windows clean-machine prerequisites remain unqualified; maintainers must test required Microsoft redistributables in a clean VM before publishing an installer. Rebuild the full runtime, not pip install into a user's production folder.
- **FFmpeg missing/libass absent:** restore both managed executables from the same verified build; --check must find CPUH264,AAC,ass/subtitles,mov_text. Font boxes/accents: install a licensed Vietnamese-compatible font, use Arial/Segoe UI/DejaVu; missing glyphs block subtitle export.
- **Already running:** use existing local dashboard or --stop with the same data directory; do not delete lock/status files while a process is alive. Separate --data-dir intentionally permits isolated instances. No fixed public port, no0.0.0.0 binding.
- **Server startup timeout/port race:** close launcher normally, inspect streamlit.log, retry. Dashboard only opens after token-scoped health passes; an unrelated service cannot be mistaken for this instance. Do not broaden firewall exposure.
- **Missing models:** open Desktop & Models and explicitly download supported CPU groups. Missing models do not block first launch. No startup download. SHA mismatch can mean changed upstream artifact/corruption; pinned expected hashes fail closed. Move broken model aside manually or restore a verified backup; downloader never overwrites existing changed files. Keep model license/attribution files. Source links/hashes in app/desktop/models.json; hashes pin locally verified artifacts and are not upstream signatures.
- **Interrupted model download:** job becomes FAILED after restart/lease; partial staging remains only in external model area if process was killed abruptly. No valid installation replaced. Stop app before manually moving incomplete staging aside. Retry explicitly, check network/disk and current heavy job.
- **Busy model download/render:** one heavy slot covers OCR/M2/M3/M4/model download. Cancel active task or wait; rerun does not automatically start a new download/render.
- **Upgrade/restore:** stop all writers and back up the whole data root. Restore into a new empty directory, verify manifest, then launch with --data-dir. A code-only update never replaces SQLite/config/originals. Never restore an old DB over newer artifacts silently.
- **Cleanup/uninstall:** --clean-temp --confirm removes only expired top-level.tmp/.part; no source/M2/M3/export/model cleanup. Removing the portable application folder leaves external data intact. No tested installer/uninstaller exists yet.

Known limits/actual test counts/build artifact details and clean-VM gaps: M5_TEST_REPORT.md. No M5 auto-merge orv1.1.0 release without owner approval.
