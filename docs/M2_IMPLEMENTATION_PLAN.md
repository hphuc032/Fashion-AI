# M2 text replacement plan

Baseline: fetched approved develop bb4b94a (owner merged M1). feature/m2-text-replacement starts there. Shared low-level migration registry/edited-approval safety commit reused as 6bd5ab6, without merging Smart Review PR #3. M2 accepts existing legacy approved mapping, so AUTO_APPROVED/MANUALLY_APPROVED are compatible when Smart Review is integrated later. No duplicate OCR/translation implementation, main/tag/merge/M3.

Pipeline: persisted M1 segments/detections → separate replacement configuration → conservative time-varying boxes → solid/blur/OpenCV inpaint/overlay-only compositor → Pillow Unicode layout → streaming FFmpeg H.264/AAC-or-audio-copy output → FFprobe validation → atomic artifact publication. CPU, one render job, originals untouched.

Tracking: use associated raw boxes and interpolate only adjacent samples within a configured gap; outside supported samples flag sparse/uncertain regions and require explicit acknowledgement/manual fixed box. Manual override stored separately. Never apply outside start <= source time < end. Simultaneous masks union before processing, text box collisions block output until adjusted. Rejected never accepted, pending only explicit per-config selection. Attribution/ownership marks excluded through an explicit content-region confirmation, no watermark removal feature.

Timing: normalize VFR to explicit rational average source FPS using FFmpeg fps filter with start_time=0, preserving presentation duration. Processing clock is exact Fraction(frame_index)/normalized_fps, not estimated original frame number. Source audio muxed from original with original relative offsets; copy compatible MP4 audio (AAC/MP3/ALAC), otherwise AAC. Output duration/aspect/resolution/audio checked against source within documented frame-level tolerance. Tests include fractional timing, real VFR normalization and AAC packet preservation/sync.

Layout: system-available Arial/Segoe UI/DejaVu sans fonts, glyph cmap verified via FontTools; no font redistribution. White/black-outline centered default, configurable size/color/stroke/shadow/background/alignment/line spacing/padding/text rectangle. Unicode word/character wrapping and font shrinking to minimum; no truncation, missing glyph or fit errors block render. Compose masks first and translated text second, preserving pixels outside selected areas before H.264 re-encoding.

Preview: selected frame only through existing frame extraction, same compositor/style/tracking used by full render. Bounded cache of before/after images, snapshot hash includes original SHA/config/segment revisions. Configuration edits never change M1 data. Snapshot captures approved content/revision; revalidate before/through/after render to prevent silently stale translations. Rights status plus explicit source/content-region confirmation required before export.

Persistence: additive render schema version 30 independent of review version 20, SQLite backup and original tables retained. replacement_configs and render_jobs with FKs/constraints/one active slot; config snapshot, source/content hash, progress/errors/output path persisted. Disposable render worker + supervisor, cancellation kills only verified job process and its FFmpeg children, cleanup only owned staging files. Atomic rename after probe; completed older outputs never overwritten by failed retries. Single job ID idempotency, fresh ID for explicit retry.

Resource limits: incremental raw BGR pipe (one frame), source pixel cap, bounded render seconds/frames, timeout and limited preview cache. FFmpeg safe list args, managed paths/UUID export names only. No deep inpainting/ASR/TTS/subtitle/cloud/downloader/posting.
